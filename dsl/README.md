# Dify DSL · 全站检索版

`ai-search-v6.yml` 是在生产 DSL「（生产勿动）AI超级搜索（加课程说明）」基础上改出的工作流，可直接导入 Dify。

生成脚本：`scripts/build-dsl-v6.py`。改了 Prompt 或节点后重跑脚本，不要手工改 yml。

```powershell
python scripts/build-dsl-v6.py "<生产 yml 路径>" "dsl/ai-search-v6.yml"
python scripts/simulate-dsl.py dsl/ai-search-v6.yml   # 分支走向模拟
python scripts/preview-dsl.py  dsl/ai-search-v6.yml output/preview.png   # 画布预览
```

画布效果见 `docs/diagrams/05-DSL-v6-画布布局.png`。

## 一、导入后必须做的 2 件事

### 1. 给 3.1 选知识库

节点「3.1 知识库-全站内容（待选数据集）」当前 `dataset_ids` 为空，导入后必须在这里选中数据集，否则该节点报错。

数据集里每篇文档按下面格式写，否则 3.3 解析节点会丢弃：

```
title: 恋爱咨询是不是骗局？先看清这三件事
type: article
summary: 三个常见误区
cover: https://cdn.6qedu.cn/article/1024.jpg
url: https://www.6qedu.cn/article/1024
author: 6Q编辑部
```

- `type` 只允许 `article` / `video` / `audio` / `mentor`
- `url` 必填，缺了不出卡
- 检索配置：混合检索，向量 0.6 / 关键词 0.4，qwen3-rerank，top_k 10

### 2. 确认 3.2 占位节点

线上课程、领袖营、6Q商城三类接口未提供。3.2 是一个返回空数组的 code 节点，不伪造数据。

开发接入时把 3.2 换成 HTTP 节点，入参 `keyword` / `intents` / `city`，出参 `items`（每项含 `id`、`type`、`title`、`cover`、`url`），再把 3.3 的 `stub_json` 指向新节点。

## 二、这一版的结构

```
2.1 开始
 └ clean_history → 2.3A shown 清洗
    └ 2.2 意图识别（8 类，intents 数组，temperature 0.1）
       └ 2.3 解析意图
          └ 2.4 主路由
             ├ CASE1 有课程名 → 2.15A → 2.15B → 2.15C → 2.15 → 2.16 → 2.17 → 2.9 / 2.9B → 2.13
             ├ CASE2 只有城市/导师 → 2.15D → 2.16 → …
             ├ CASE3 内容类 → 2.4B
             ├ CASE4 闲聊 → 2.18 → 闲聊回复
             └ ELSE → 没找到内容
课程链出口（2.13 / 2.12 / 课程异常 / 补充信息）→ 2.4B
2.4B → 3.1 → 3.2 → 3.3 → 3.3B → 3.4 → 3.5
3.3B 无结果 → 没找到内容
```

- **2.4B** 是课程与内容并存的开关：课程答案先出，再接着出内容分区
- **3.3B** 判断内容是否有结果，无结果直接走「没找到」，避免出现空导语加空卡片
- 画布按泳道摆：入口在左，课程链横向展开，出口收成一列，内容链在右侧单独一条

## 五、调参位置

| 位置 | 参数 | 现值 | 说明 |
|------|------|------|------|
| 2.2 意图节点 | temperature | 0.1 | 分类任务不要高于 0.2 |
| 3.1 知识库 | top_k | 10 | 组装时每类只取 3 条 |
| 3.3 代码节点 | `MIN_SCORE` | 0.30 | 低于此分丢弃；设 0 会导致任何输入都出卡，「没找到」永不触发 |
| 3.3 代码节点 | `PER_TYPE_LIMIT` | 3 | 每类最多出卡数 |

## 六、已知限制

1. **串行执行**：命中课程+内容时先后跑，首屏耗时叠加。接口齐了再评估并行。
2. **知识库召回上限**：top_k 限制，做不了「共 128 条、查看全部」。
3. **商城价格**：知识库只出目录，价格必须等接口，不要从知识库读 `price`。
4. **导师类**：没有导师实体数据时该类永远为空，会静默不渲染。
5. **画布偏宽**：约 6100×1900，导入后按「适应画布」查看。
